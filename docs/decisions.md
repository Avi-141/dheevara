Newest last. Each entry: date, decision, reason.

- **2026-10-03 — No local fallbacks for providers.** Avi's call. Every voice, render and search step calls the real service; when it cannot, it fails. Reason: fallbacks would hide the real cost, latency and quality we are trying to measure.
- **2026-10-03 — Planner and QC run in chat, not via the Anthropic API.** Claude in the build session writes beat maps, shot contracts and QC verdicts as committed files. Reason: no API key needed, and every verdict is reviewable in git.
- **2026-10-03 — Drive output folder.** The Drive connector only sees files it creates, so output goes to "Dheevara — Build Output" (My Drive), which Avi can move into his own folder.
- **2026-10-03 — Mockups before the app.** The full product surface is mocked at 390×844 and reviewed by four reviewer agents (art direction, scholarship, product, accessibility) before any app code.
- **2026-10-03 — Jev is the general decision layer.** The `apikey_…` key belongs to Jev, which Avi wants available for storyline and video-generation decisions and any routing inside the pipeline. Docs: https://docs.typesafe.ai/introduction (typesafe.ai). Read from `JEV_API_KEY`; base URL from `JEV_BASE_URL`. Blocked: `docs.typesafe.ai` and its API host are not on the network allowlist yet.
- **2026-10-03 — Cold open before the book page.** Chapter grammar becomes: cold open (a 5–8 s witness shot) → the verse, chanted → witness scene → hidden detail → the question. Lineage is available at any moment from the scene, not a timed beat. Reason: the product review showed the first scene landing at 30–40 s when the chapter opened on the page, and the first 30 s decide retention.
- **2026-10-03 — Product language v2: sleek and clean.** One sans (Geist) for all interface text; Tiro Devanagari Sanskrit only for verse; Noto Sans for the other Indic scripts. Near-black with one accent, amber, which only ever means "source". Sindoor only means "now". Primary buttons are off-white. Flex layouts that hold at 360×740. Reason: Avi asked for a much sleeker, cleaner language; reviewers found layout collisions and contrast failures in v1.
- **2026-10-03 — The look: temple relief, lit by one lamp.** Ellora basalt for the Mahābhārata, Hampi granite for the Rāmāyaṇa; painted-miniature register only on still surfaces (reveal and share cards). Reason (art director): reads as darśan rather than cartoon, stone hides AI drift in faces and costume, raking light gives video models depth. Avi to confirm.
- **2026-10-03 — Wording follows the critical edition.** Popular images (seven rings, "sixteen", the womb story) are presented as the popular telling, never as the text. Chapter 3 is "The way in", not "The seventh ring". Reason: scholar review; the reveal cannot criticise popular claims the rest of the chapter states as fact.
- **2026-10-03 — Release and free rules.** Chapter 1 of every season is free. Members get every released chapter. Pilot launches with chapters banked; new chapters land at 7 pm in the viewer's timezone. Autoplay to the next chapter can always be stopped and can be turned off.
- **2026-10-04 — Style bible drafted.** `design/style-bible.md` sets the look (living temple relief under one lamp), light, palette, camera grammar per beat, witness vantages, faces and violence rules, period never-list, prompt fragments for the compiler, the QC checklist, sound and caption type. Binding once Avi confirms the look.
- **2026-10-04 — Session ownership.** Three sessions work in parallel: pipeline (`src/`, `schema/`, `content/`, `services/`, `web/`), app (`apps/`), and design and product research (`design/`, `docs/research/product/`). Decisions stay in this file.
- **2026-10-04 — Proposed, for Avi: research-led changes.** From `docs/research/product/synthesis.md`: (1) pilot arc from the Rāmāyaṇa (Sundara Kāṇḍa), with free pieces live the week *Ramayana* Part 1 opens on 6 Nov 2026; s1e3 stays the pipeline's v0 test; (2) pilot languages English, Hindi, Telugu, Gujarati, Tamil, with Kannada and Malayalam in the first wave; (3) price tests: India ₹1,499 and ₹1,999 a year, ₹99 against ₹149 a month; diaspora $49 family and a quarterly plan; (4) "authority" means visible per-line citation and a named scholar's reply, since Mythik is scholar-advised; (5) paid launch at the April 2027 festivals. Not adopted until Avi says so.
- **2026-10-04 — AI disclosure built in.** Following India's synthetic-content rules: burned-in label on every exported cut, a spoken disclosure before AI narration and chant, and C2PA provenance on every asset (style bible section 13). Lawyer review still required before anything is public.
- **2026-10-04 — Chapter order in the season.** Chapter 4 answers chapter 3's question, so it is "The gatekeeper" (Jayadratha, 3.256 and 7.41–42); "Arjuna's vow" (7.50–51) is chapter 5. Reason: design review; the cliffhanger must be answered by the very next chapter.
- **2026-10-04 — Tests on node:test; contracts on strict Ajv (draft 2020-12).** The pipeline's tests use Node's built-in runner (`node --test`), with no test framework dependency; schemas are JSON Schema 2020-12 compiled by Ajv in strict mode with all errors collected, and the validator turns each error into a sentence naming the field and the rule it enforces. Reason: fewer dependencies to audit and pin, strict mode catches schema typos at compile time, and a contract author reads one plain list of what to fix.
- **2026-10-04 — gitleaks pinned at 8.30.1 and installed into `.tools/bin`.** `scripts/gitleaks.sh` installs exactly that version (gitignored `.tools/bin`), from the release tarball checked against its published sha256 list, or, where GitHub release downloads are blocked (as in the cloud container's proxy), by `go install` through the Go module proxy, which Go's checksum database verifies. There is no unchecked fallback. The pre-commit hook (`.githooks`, set by `pnpm install`) and `pnpm secrets` in CI both use it with `.gitleaks.toml`. Reason: rule 8 and DHE-31; a pinned, verified binary makes the hook behave the same on every machine and in CI.
- **2026-10-04 — Witness allowlist and revered list live in code until the canon carries them.** The shot contract schema allows three witnesses (`sanjaya`, `vanara`, `charioteer`); adding one is a decision in this file. `REVERED` in `src/contract/rules.mjs` names the figures never framed close on the face; it may be extended, never shortened, without a scholar's note. In M5 both move to flags on canon person records (witness-eligible, revered), set with scholar review, and the contract checks read them from the canon. Reason: rule 1 needs a gate now, before the canon exists, and a hard-coded list is the smallest honest one.
